# Windows 版源代码说明

CueClock 的 Windows 版**和 macOS 版是同一份源代码**（TypeScript：引擎 `engine/`，界面 `app/` 用 Electron + React），没有单独复制一份——复制会让两份各自改、慢慢对不上。Windows 版 = 这份代码 + 下面这些 Windows 专用的部分。整个仓库就是 Windows 版源码；GitHub 上的版本标签 `windows-v*`（Releases 页面）是它的快照，页面上的「Source code (zip)」就是这个版本的完整源码。

## Windows 专用 / 与平台有关的源文件

| 文件 | 作用 |
|---|---|
| `windows/build-windows.mjs` | 打包脚本：构建 → 套上 Windows 版 Electron → 生成免安装文件夹和 zip（在 macOS / Linux / Windows 上都能运行） |
| `windows/使用说明.txt` | 随程序一起发给用户的说明（SmartScreen、防火墙、数据位置、开机启动、已知限制） |
| `windows/sign.ps1` + `windows/Fawen-CodeSigning.cer` + `windows/trust-fawen-certificate.ps1` | 代码签名为 Fawen：签名脚本（私钥来自 Secrets，不在仓库）、公钥证书、让一台电脑信任该证书的脚本 |
| `windows/install-guard-task.ps1` | 可选：用「任务计划程序」做崩溃后自动重启（未在现场验证） |
| `windows/README.md` | 获取 / 安装 / 与 macOS 版差别 / 验证情况 |
| `.github/workflows/windows.yml` | GitHub Actions：在真实 Windows 机器上测试、打包、用打包出来的 exe 做启动冒烟 |
| `engine/src/atomic.ts`（+ `engine/test/atomic.test.ts`） | 「写临时文件再改名覆盖」在 Windows 上目标被占用（EPERM / EBUSY / EACCES）时退避重试；**由 CI 在真实 Windows 上发现并修复** |
| `engine/src/paths.ts` | 状态目录：Windows 为 `%APPDATA%\CueClock` |
| `engine/src/health.ts` | 在线检测 Ping 的 Windows 参数（`-n 1 -w <毫秒>`），只认输出里的 TTL，隐藏控制台窗口 |
| `engine/src/sleepguard.ts` | 「防止电脑休眠」目前只支持 macOS（Windows 上该选项不可用） |
| `app/electron/autostart.ts` | Windows 开机自启：用 Electron 登录项（`setLoginItemSettings`）；macOS 用 LaunchAgent（`autostartMac.ts`） |
| `app/electron/main.ts` | `app.setAppUserModelId`（任务栏 / 通知标识）、窗口图标（非 macOS）、托盘 |
| `app/electron/supervisor.ts` | 拉起引擎时 `windowsHide: true`（不弹控制台窗口） |
| `app/scripts/release.mjs` | 一键切换正式版本——**只支持 macOS**（Windows 上手动替换文件夹） |
| `app/scripts/verify-isolated.mjs` | 隔离验收；Windows 默认拒绝运行，设置 `CUECLOCK_WINDOWS_VERIFY=1` 才放行（试跑，见下） |

## 在 Windows 上构建 / 运行

```powershell
cd engine ; npm ci ; npm test                      # Node >= 22.18
cd ..\app ; npm ci ; node node_modules\electron\install.js   # 新版 npm 默认不执行安装脚本，需手动下载 Electron 运行时
npm test ; npm start                                # 开发运行
node ..\windows\build-windows.mjs                   # 打包 → windows\dist\CueClock-<版本>-win-x64.zip
```

## 在 Windows 上验证到什么程度

- **真实 Windows（GitHub Actions `windows-latest`）验证过**：安装依赖；引擎与界面类型检查；引擎与界面全部单元测试（修复 `EPERM` 后全部通过）；构建与打包；打包出来的 `CueClock.exe --smoke-test` 启动引擎、连接并退出码 0。
- **未验证**：Electron 界面自检 `verify:isolated` 在 Windows 上（试跑时卡住超时，原因没查）；窗口里的实际显示（字体、高 DPI 缩放、托盘）；开机自启；`install-guard-task.ps1`；防火墙下的 UDP 收发；真实设备；长期运行；机构颁发的代码签名证书（现在是自签名）与安装程序。
