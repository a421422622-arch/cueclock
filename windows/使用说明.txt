CueClock（UDP / TCP 中控时间线）— Windows 版

【怎么用】
1. 把整个文件夹解压到一个固定位置，例如 C:\CueClock\（不要放在「下载」或临时目录里，也不要放在会被网盘同步的目录里）。
2. 双击 CueClock.exe。第一次运行 Windows 可能提示「Windows 已保护你的电脑」：点「更多信息」→「仍要运行」。
   （程序没有购买代码签名证书，所以会出现这个提示；这是正常的。）
3. 第一次运行时 Windows 防火墙会问是否允许网络访问：请选「专用网络」并允许。需要接收 UDP 触发（监听端口）时必须允许，否则收不到。
4. 窗口右上角的 × 只是把界面收到系统托盘（右下角），引擎和日程继续运行。要真正退出：托盘图标右键 → 「退出界面（引擎继续运行）」或「退出并停止引擎…」。

【数据在哪】
  %APPDATA%\CueClock\      （在资源管理器地址栏输入这个就能打开）
  里面有：项目配置、自动备份、日志、操作记录。重装或换电脑时，用界面里的「配置管理 → 导出备份包 / 从备份包恢复」最省事。

【开机自动启动】
  界面里「配置管理 → 软件设置」勾选「开机自动启动」。
  注意：Windows 版目前没有 macOS 版那种「崩溃后自动拉起」的系统守护；界面会在引擎崩溃时重新拉起引擎，但界面本身崩溃不会自动重启。
  需要更强的守护，请看 windows/README.md 里的「任务计划程序」做法。

【已知限制（Windows 版）】
- 「运行时防止电脑休眠」选项目前只有 macOS 有。Windows 上请在「电源和睡眠」里把「睡眠」设为「从不」。
- 没有代码签名（见上）。
- 这个版本是在 macOS 上交叉打包 + GitHub Actions 的 Windows 机器上跑自动测试得到的；是否在你的现场电脑和真实设备上正常，需要实际验收。

遇到问题：把「配置管理 → 导出备份包」得到的文件发给维护的人，里面有运行状态、最近日志和操作记录。
